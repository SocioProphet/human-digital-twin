## Binding protection rules

FCBCP/HSP-Map/Trueman Mesh in this repository are research-only unless an external review path exists.

Default blocks:

- human actuation;
- uncontrolled human-contact protocols;
- raw private physiological telemetry export;
- unsupported wave-genetics mechanisms;
- semantic wave-texts;
- DNA-as-inductor/speaker/microphone/laser/magnet mechanisms;
- autonomous high-impact decisions about a person.
